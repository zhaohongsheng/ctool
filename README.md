# CTool 万能工具箱

一个以浏览器本地运行为主的开发者工具箱 Chrome 扩展（Manifest V3）。无需账号、无需配置：AI 问答内置 OpenCode Zen 免费模型，打开即可提问；除 AI 问答、GitHub 镜像测速与主动发起的镜像访问外无需联网，所有输入、转换与生成结果都只留在本机（使用加速直链或镜像访问页面时会把链接交给第三方镜像站点，详见「GitHub 镜像加速」）。

### 国际化与个性化

- 左下角可在简体中文与 English 之间切换，选择会写入 `localStorage` 与 `chrome.storage.local`，刷新、重开小窗或打开多个标签页后都会保持。
- 日期、星期、相对时间与数字格式会跟随当前语言。
- 工作台提供 12 种常见职业，选择后自动推荐对应工具；推荐结果与收藏都会持久保存。
- 收藏的工具会出现在左侧“我的收藏”分组，也可以在工作台卡片上直接点亮星标。
- 工作流支持清洗文本、提取邮箱与链接、JSON 转 CSV，以及一键打开 XML / SQL / 文件哈希 / 图片 Base64 / Lorem 等工具。

### AI 问答

- **零配置**：默认内置 [OpenCode Zen](https://opencode.ai/zen/v1) 的免费模型（id 含 `-free`），打开工具直接提问，无需账号、接口地址或 API Key。
- 点「刷新模型」从 `/models` 拉取最新免费池；请求遇到限流、区域限制或 5xx 时先自动切换下一个免费模型，仍失败则自动回退到 **Pollinations 公共备用端点**（`https://text.pollinations.ai/openai`，同样免 Key，可在高级设置中关闭）。关闭回退时才改为刷新模型池后重试。
- 高级设置可填入自己的 Zen API Key 提升稳定性；也可切到「自定义接口」使用任意 OpenAI 兼容服务（`/v1/chat/completions`），本地 Ollama 可留空 Key。设置自动保存，无需点击保存按钮。
- 支持流式输出（逐字显示）。扩展页面直连若被 CORS 拦截会自动改由 service worker 发请求；油猴版通过 `GM_xmlhttpRequest` 桥绕开 iframe 限制，改为使用完整响应（非流式）。
- **选中文本直接问**：网页选中文字后右键「用 CTool 处理 → 💬 问 AI（免配置）」，文本会自动载入并直接提问，不需要复制粘贴。
- **隐私**：AI 问答会把问题发送到 OpenCode Zen（或你配置的服务），Zen 不可用时改用 Pollinations 公共端点，两者都是第三方服务；免费模型的提示词可能用于改进模型，请勿提交个人或机密信息；API Key 仅保存在本机 `localStorage`。AI 问答与 GitHub 加速是仅有的两个可能联网的工具，其余工具仍然完全离线。
- 免费额度由第三方共享，OpenCode 可能随时调整客户端校验或限流策略（实测部分网络会被判为 `FreeUsageLimitError`）。默认会自动回退到公共备用端点；也可以填入自己的 Zen Key 或切换到自定义接口。

### 交互特性

- 点击工具栏图标或按 `Ctrl+Shift+Y` 打开完整工具箱页面。
- 再次打开时复用已存在的工具箱标签页，不会重复创建。
- 每个普通网页右下角都有一个 CTool 悬浮图标，点击即可在当前页面内打开小窗，不必离开原网页。
- 小窗与完整工具箱共用同一个 `toolbox.html` 页面：顶部下拉框可以选择全部 36 个工具，选中后直接在小窗中执行。
- 选中网页文本后右键 → **用 CTool 处理**，会在当前网页内的小窗中载入选中文字并自动执行对应操作；选中文本菜单共 20 项，覆盖编码解码、格式化、哈希、二维码、URL、JWT 与 GitHub 链接加速等常用处理。在 GitHub 链接上右键还有 3 项「⚡ 用 CTool 加速此链接 / ⚡ CTool 一键加速下载 / 🌐 用镜像访问此链接」，可把链接传参到工具或直接打开镜像页面。
- 小窗可以随时展开为完整工具箱，当前工具与输入内容会一并带过去。
- 左侧导航支持多关键词搜索（按 `/` 聚焦搜索框）。
- 工具地址带 `#工具ID` 哈希，可直接收藏或刷新后恢复。
- 深色 / 浅色主题与语言选择都会记住上次设置。
- 复制按钮优先使用当前页面的剪贴板能力；输入框内支持 `Ctrl+Enter` 快速执行。
- 响应式布局，窄窗口下自动收起侧边栏，小窗模式下自动使用紧凑布局。
- 每天首次打开工具箱会提示一次「赞赏支持」，点关闭后当天不再出现；提示状态只保存在本机 `localStorage`。

### GitHub 镜像加速

- 粘贴 GitHub 直链（Release 附件、源码包、Raw 文件、Blob / 仓库页、Git 克隆地址等），自动识别类型，并按启用的镜像节点生成「镜像前缀 + 完整 GitHub 链接」直链。
- **无需复制粘贴**：打开 GitHub / Gist 页面时，Release 附件、源码包、Raw、LFS 与 Patch 链接旁会自动出现 ⚡ / ↓ 两个图标。⚡ 把链接作为参数送进 CTool 并生成直链，↓ 额外用首选镜像直接发起下载，随后自动收起小窗。
- 页面右下角的小胶囊显示识别到的链接数，点击一次把本页全部链接（最多 20 条）批量载入工具；工具页的「扫描本页链接」按钮可在完整工具箱里主动重新抓取来源标签页。
- 链接上右键 → **⚡ 用 CTool 加速此链接** / **⚡ CTool 一键加速下载** 同样无需复制；输入框下方的开关可随时关闭页面图标（写入本机 `ctool.githubPageBadges` 与 `ctoolGithubBadges`）。
- 页面识别由 `js/page-github.js` 在 GitHub 域名内完成，使用 Shadow DOM 注入图标，不改写原链接、不联网、不读取其他页面内容；Turbo / pjax 站内跳转会自动重扫。
- **网页访问加速已下线**：2026-11 实测 `githubfast.com` 对浏览器返回 403「To prevent abuse, only git and CLI access are allowed」（只支持 git / CLI），`bgithub.xyz` / `kkgithub.com` / `gitclone.com` / `github.ur1.fun` 等已关停或反爬，没有可用的同构镜像站。因此移除了 🌐 图标、「加速访问此页面 / 加速当前页」、镜像站检测与自动代理，不会再把用户送到打不开的地址。
- 工具页精简为「加速结果 / 设置与说明」两个标签页：粘贴链接点一次「⚡ 一键加速」即可生成下载直链；节点管理、页面开关与说明都收进设置页折叠区。⚡ / ↓ 下载走 `gh-proxy.com` 一类文件代理（只转发文件字节、不返回网页 HTML）。
- **站内链接统一新标签页**：GitHub 页面里的普通站内网页链接（仓库 / 文件 / 目录 / Release / Issues 等）左键点击时由页面注入器拦截，交给后台新开标签页直连 `github.com`；带 Ctrl / Cmd / Shift / Alt、`target="_blank"`、下载属性以及下拉 / Tab 等 JS 控件都保留浏览器与 GitHub 原有行为，不改写 `href`。
- 设置页里三个可选开关：页面图标与「GitHub 站内链接默认在新标签页打开」默认开启，「加速页面内 GitHub 图片 / Raw 资源」默认关闭；图片加速把 README / Issue 图床图片交给**下载代理首选节点**加载，关闭时恢复原始 `src` / `srcset`。
- 设置页「下载代理节点」管理**文件代理**（2026-11 用真实 raw 文件逐项复测，默认启用 8 个返回 200 且内容正确的站点：`gh-proxy.com`、`edgeone.gh-proxy.org`、`gh.monlor.com`、`ghproxy.net`、`ghfast.top`、`githubproxy.cc`、`ghfile.geekertao.top`、`github.ednovas.xyz`），可启用 / 停用、添加自定义、恢复默认。偏好与测速结果只写在本机 `localStorage`。
- 点击「测速」才并发发送 HEAD 请求测延迟，默认完全不联网；结果缓存 5 分钟并按延迟排序，最快节点标为「首选」。405 / 501（镜像不支持 HEAD）不计为节点失效。所有「打开」按钮、页面图标、右键菜单与站内链接点击一律新标签页，不会替换当前页面或小窗。
- 仓库页 / 文件页会派生 Raw 直链、main / master 源码包 ZIP、TAR.GZ 与 `git clone` 地址；结果页的「派生链接与 git clone 命令」折叠区可复制单仓库克隆命令与全局 `insteadOf` 重写命令。
- 支持一行一个批量生成（最多 20 行）、复制全部直链、复制 / 打开 / 下载首选直链；下载使用原生 `a[download]` 点击，不经 Blob 中转，便于 Gopeed 等下载器接管。
- 选中 GitHub 链接后右键 → **用 CTool 处理 → GitHub 链接加速**，会在小窗中自动载入链接并直接生成结果。
- 镜像由第三方运营：打开加速链接或测速时，对方能看到完整 GitHub 链接（可能含令牌参数）。私有仓库、带鉴权参数的链接不要使用第三方镜像；镜像可用性、速度与返回内容本工具不作保证。

### 网页资源下载

- 一个页面自动扫描出 **IMG 图片 / DOC 文档 / MED 媒体 / TBL 表格** 四类资源，按类型分组显示，每组都可一键全选。
- **IMG 图片**：提取 `<img>`、`srcset` 当前图、CSS 背景图、视频海报、懒加载图片、`og:image` / `twitter:image` 分享图和 Canvas 画布。
- **DOC 文档**：提取 PDF、Word、Excel、PowerPoint、电子书、压缩包、安装包等直链；识别 `download` 属性、嵌入文件、`data-*` 下载地址、JSON-LD 文档地址、网络请求中的文档资源，以及链接文字/路径中含“文库、文档、附件、下载、PDF”等关键词的链接；百度文库等常见文档站点至少会把当前文档页加入列表。
- **TBL 表格**：识别 HTML 表格（自动处理 `rowspan` / `colspan`），并把页面的 `<ul>` / `<ol>` / `<dl>` 及 `role="list"` 列表转换为表格；列表项若包含统一分隔符（`|`、`-`、`：` 等）会自动拆分成多列，可预览并导出带 UTF-8 BOM 的 CSV（Excel 可直接打开）。
- **MED 媒体**：提取 `<video>`、`<audio>`、`<source>`、懒加载 `data-src`、字幕轨和媒体文件直链；m3u8 / mpd 会标注为流媒体清单。
- 支持选择目标标签页、自动扫描、按类型或单条勾选，下载选中项、复制链接，或把所有勾选项打包成 `ctool-downloads.zip`。
- 下载文件统一保存到浏览器下载目录下的 `CTool/下载` 文件夹，重名文件自动加序号；ZIP 内的重名成员也会自动加序号。

## 安装

### Chrome / Edge（桌面版）

1. 解压发布包，或直接使用 `ctool` 目录。
2. 打开扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的 `ctool` 目录。
5. 将 **CTool 万能工具箱** 固定到工具栏，点击图标即可使用。

要求 Chrome / Edge 111 或更高版本（界面使用了 `color-mix()`）。

## 使用

- **打开工具箱**：点击工具栏图标，或按 `Ctrl+Shift+Y`。
- **网页悬浮小窗**：
  1. 在任意普通网页右下角找到 CTool 悬浮图标；
  2. 点击图标，页面内会打开小窗；
  3. 在小窗左侧工具栏选择 36 个工具中的任意一个，直接使用；
  4. 点击小窗右上角的展开按钮可转到完整工具箱，点击关闭按钮或按 `Esc` 收起小窗。
- **切换语言**：点击左下角的语言下拉框选择“简体中文”或“English”，刷新或重开页面后仍然生效。
- **工作台与收藏**：打开左侧“工作台”，选择职业查看推荐工具；点击任意工具右侧的星标即可收藏，收藏会出现在左侧“我的收藏”分组。
- **AI 问答**：打开「AI 助手 → AI 问答」直接输入问题即可，默认走 OpenCode Zen 免费模型、无需任何配置。想用自己的服务时切到「自定义接口」，填写地址、模型与 API Key（本地 Ollama 可留空），设置自动保存并支持流式输出；选中文字后也可以右键「💬 问 AI（免配置）」直接提问。
- **GitHub 加速**：打开「网页下载 → GitHub 加速」，粘贴链接点「⚡ 一键加速」，下载直链出现在「加速结果」页，直接复制 / 打开 / 下载即可；节点与开关都在「设置与说明」页，需要排序时点「测速」。所有「打开」按钮、页面图标、右键菜单与 GitHub 站内链接点击默认新标签页，不替换当前页。更省事的是不复制：在 GitHub 页面点下载链接旁的 ⚡ / ↓ 图标，或右键使用 CTool 菜单；「扫描本页」可一次抓取来源标签页的全部链接。网页访问加速已下线。
- **右键处理选中文本**：
  1. 在任意网页选中文字；
  2. 右键 → **用 CTool 处理**；
  3. 选择 Base64 / URL / HTML 实体 / Unicode 的编码与解码、JSON 格式化或压缩、XML / SQL 格式化、文本统计、计算哈希、解析或验证 JWT、生成二维码、解析 URL、Markdown 预览、GitHub 链接加速、问 AI（免配置）等；
  4. 当前网页内的小窗会自动打开、载入文本并执行对应操作；
  5. 可以继续修改输入或切换工具，点击右上角的展开按钮可转到完整工具箱。
- **搜索工具**：按 `/`，输入名称或关键词，按 `Enter` 打开第一个结果，按 `Esc` 清空。
- **切换主题**：点击右上角的太阳 / 月亮按钮。
- **下载网页资源**：
  1. 在要处理的网页上点击工具栏图标（或从该网页右键打开 CTool），工具箱会记住来源标签页；
  2. 打开 **网页下载**，工具会自动扫描当前页面并按 IMG / DOC / MED / TBL 分组；
  3. 在“目标网页”下拉框中确认页面，必要时点击“扫描页面”重新扫描；
  4. 通过顶部类型标签筛选，或直接勾选类型组、单条资源；点击“下载选中”批量下载，点击“打包下载 ZIP”合并导出；
  5. 表格和列表支持预览，勾选后可连同其他资源一起下载或打包。

> 首次安装或更新后，如果出现“读取和更改所有网站数据”的权限提示，请允许，否则无法扫描网页内容。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存主题、上次使用的工具、右键菜单待处理文本与来源标签页 |
| `contextMenus` | 提供“用 CTool 处理”的右键菜单 |
| `tabs` | 查找并复用工具箱标签页，列出可扫描的网页标签页 |
| `clipboardWrite` | 复制转换结果、资源链接或 CSV 到剪贴板 |
| `scripting` | 在用户选择的网页中读取图片、链接、表格和媒体信息，并在扩展更新后注入悬浮入口 |
| `downloads` | 批量下载网页资源并保存到分类文件夹 |
| `<all_urls>` | 允许在普通网页中显示悬浮图标、打开小窗、扫描用户选择的网页，以及为 GitHub 加速的测速请求与新标签页提供权限；页面图标只在 GitHub 域名注入；不会在后台自动读取页面 |

- 页面图标由 `js/page-github.js` 在 GitHub 域名内注入 Shadow DOM，只读取 `a[href]` 的链接地址，不改写链接、不读取正文、不联网；开关状态只写入本机 `ctool.githubPageBadges` / `ctool.githubNewTabLinks` / `ctool.githubImageBoost`（扩展侧同步为 `ctoolGithubBadges` / `ctoolGithubNewTabLinks` / `ctoolGithubImageBoost`）。
- 网页访问加速已下线，不再连接任何第三方网页镜像；只有主动点「测速」或开启图片资源加速才会访问文件代理节点。图片加速前缀写在本机 `ctoolGithubImageNode`，旧版镜像站偏好 `ctool.githubVisitNode` / `ctoolGithubVisitNode` 与自动代理 `ctool.githubAutoVisit` 会被清空，不会残留域名替换行为。
- GitHub 加速的链接解析、直链拼接、节点启用状态与测速缓存都在本机完成（`ctool.githubCustomNodes` / `ctool.githubNodeEnabled` / `ctool.githubProbeCache`），不会上传。
- 只有主动点击「测速并选最快」时才会向启用的镜像节点发送一次 HEAD 请求；打开或下载加速直链时由浏览器直接访问第三方镜像，对方能看到完整 GitHub 链接。镜像由第三方运营，CTool 不保证其可用性、速度或返回内容。
- 扩展不包含任何远程脚本、统计代码或后台网络请求；二维码生成与识别、ZIP 打包所用的第三方库与赞赏码图片都随扩展打包在本地。
- 赞赏提示的显示与关闭状态只写入本机 `localStorage`，不上传到任何服务。
- 二维码识别在本机 canvas 上读取像素完成（jsQR 1.4.0，Apache-2.0，许可证见 `js/vendor-jsqr-LICENSE.txt`），图片不会上传。
- 扫描网页时，提取到的资源列表只在工具箱页面内存中处理，不会上传到服务器。
- 右键菜单带入的文本只在页面内通过 `postMessage` 交给当前标签页的小窗；回退到独立小窗时才通过 `chrome.storage.local` 短暂传递，读取后立即删除。
- 悬浮图标只负责打开小窗，不会主动读取页面内容；只有在小窗中选择网页下载工具并点击扫描时，才会读取当前页面的资源信息。
- 下载由浏览器下载管理器完成；扩展本身不会把文件内容发送到第三方。
- 生成的密码使用 `crypto.getRandomValues()`，不会上传或保存。
- `chrome://`、`edge://`、扩展商店等受保护页面不会显示悬浮图标，也无法扫描；右键菜单在这些页面会退回独立小窗。`file://` 页面需要在扩展详情中手动开启“允许访问文件网址”。

## 开发与打包

扩展本体没有构建步骤，修改源码后在扩展管理页点击“重新加载”即可。只有需要生成油猴单文件版时，才运行下面的可选构建命令。

打包为 ZIP 时，让 `manifest.json` 位于压缩包根目录：

```powershell
Compress-Archive -Path F:\ctf\ctool\* -DestinationPath F:\ctf\ctool.zip -Force
```

### 油猴单文件版（ctool.user.js）

部分平台只允许上传 `.js` 文件、无法提交扩展包。运行下面的命令，可从现有源码生成一份自包含的 UserScript：

```bash
node build-userscript.js
```

产物 `ctool.user.js`（约 1.3 MB）把 `toolbox.html`、`css/style.css`、17 个脚本与两张赞赏码全部内联（图片按文件魔数转 Data URL），零外部依赖、默认不发起网络请求，可直接安装到 Tampermonkey / Violentmonkey，或上传到只接受 `.js` 的脚本平台。源码改动后重新运行该命令即可刷新产物，**不要直接编辑生成的文件**。

使用方式：页面右下角圆形 **C** 按钮、油猴菜单中的「打开 / 关闭 CTool 工具箱」，或快捷键 `Alt+Shift+C`。工具箱运行在隔离 iframe 中，不污染宿主页面样式；主题、语言、收藏、赞赏提示关闭状态等偏好通过 `GM_getValue` / `GM_setValue` 跨站点保存。

宿主页面侧同样内联 `js/page-github.js`：GitHub 页面链接旁的 ⚡ / ↓ / 🌐 图标、右下角批量胶囊、一键传参、自动下载、网页镜像访问与图片资源加速在油猴版同样可用；扫描、下载与打开标签页由页面上下文完成，个别站点的 CSP 可能限制脚本运行，此时建议改用完整版扩展。

与扩展版的差异：

| 能力 | 油猴版 |
| --- | --- |
| 36 个工具 | 除「网页资源下载」外全部可用；该工具会显示不可用说明（依赖 `tabs` / `scripting` / `downloads` 扩展 API，连同 ZIP 打包一起不可用） |
| 悬浮小窗、右键菜单 | 由悬浮按钮、菜单命令与快捷键替代 |
| AI 问答 | 默认可用：通过 `GM_xmlhttpRequest` 桥请求 OpenCode Zen，绕开 iframe 的 CORS 限制；使用完整响应（非流式），自定义接口也可走同一通道 |
| GitHub 加速 | 直链生成、派生链接、克隆命令、页面图标、一键传参、站内链接新标签页与图片资源加速均可用；网页访问加速已下线；测速在 iframe 中受页面 CORS / CSP 限制，只能作为连通性参考，建议改用完整版扩展 |
| 每日赞赏提示 | 保留，状态跨站点同步 |

iframe 使用 `srcdoc` 内联脚本。若目标站点设置了严格的 `Content-Security-Policy` 禁止内联脚本，工具箱会显示提示并允许在新标签页打开；这类站点建议改用完整版扩展。

## 说明

- 本扩展面向桌面版 Chrome / Edge；移动端浏览器不支持扩展。
- 所有转换均在本地完成，但请仍然避免在不可信设备上处理敏感凭据。
- GitHub 加速不会绕过任何访问控制：镜像只转发链接，能否下载取决于镜像站点与目标资源是否公开可用。
- 下载工具只能获取浏览器页面中可见或可访问的资源：受 DRM 保护的视频、需要登录鉴权的临时地址、未渲染的虚拟滚动列表、图片中的文字表格、`chrome://` 页面以及部分防盗链资源可能无法直接下载。
- m3u8 / mpd 下载的是流媒体清单文件本身，不是合并后的视频；如需完整视频，请使用专门的流媒体下载工具。
- 扫描结果是页面当前状态的快照，页面动态加载更多内容后请点击“扫描页面”重新获取。
