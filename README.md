# CTool 万能工具箱

一个完全在浏览器本地运行的开发者工具箱 Chrome 扩展（Manifest V3）。无需账号，除可选的 AI 问答外无需联网，所有输入、转换与生成结果都只留在本机。

### 国际化与个性化

- 左下角可在简体中文与 English 之间切换，选择会写入 `localStorage` 与 `chrome.storage.local`，刷新、重开小窗或打开多个标签页后都会保持。
- 日期、星期、相对时间与数字格式会跟随当前语言。
- 工作台提供 12 种常见职业，选择后自动推荐对应工具；推荐结果与收藏都会持久保存。
- 收藏的工具会出现在左侧“我的收藏”分组，也可以在工作台卡片上直接点亮星标。
- 工作流支持清洗文本、提取邮箱与链接、JSON 转 CSV，以及一键打开 XML / SQL / 文件哈希 / 图片 Base64 / Lorem 等工具。

### AI 问答

- 支持任意 OpenAI 兼容接口（`/v1/chat/completions`），可填写系统提示词与温度。
- 支持流式输出，回答会逐字显示；也可以关闭流式输出使用普通请求。
- API Key 仅保存在本机 `localStorage`，不会同步或上传；使用 Ollama 等本地服务时可以留空。
- AI 问答是唯一可能联网的工具，其他工具仍然完全离线。发送前会把问题与配置的接口地址发送到你自己填写的服务。

### 交互特性

- 点击工具栏图标或按 `Ctrl+Shift+Y` 打开完整工具箱页面。
- 再次打开时复用已存在的工具箱标签页，不会重复创建。
- 每个普通网页右下角都有一个 CTool 悬浮图标，点击即可在当前页面内打开小窗，不必离开原网页。
- 小窗与完整工具箱共用同一个 `toolbox.html` 页面：顶部下拉框可以选择全部 35 个工具，选中后直接在小窗中执行。
- 选中网页文本后右键 → **用 CTool 处理**，会在当前网页内的小窗中载入选中文字并自动执行对应操作；菜单共 19 项，覆盖编码解码、格式化、哈希、二维码、URL 与 JWT 等常用处理。
- 小窗可以随时展开为完整工具箱，当前工具与输入内容会一并带过去。
- 左侧导航支持多关键词搜索（按 `/` 聚焦搜索框）。
- 工具地址带 `#工具ID` 哈希，可直接收藏或刷新后恢复。
- 深色 / 浅色主题与语言选择都会记住上次设置。
- 复制按钮优先使用当前页面的剪贴板能力；输入框内支持 `Ctrl+Enter` 快速执行。
- 响应式布局，窄窗口下自动收起侧边栏，小窗模式下自动使用紧凑布局。
- 每天首次打开工具箱会提示一次「赞赏支持」，点关闭后当天不再出现；提示状态只保存在本机 `localStorage`。

### 赞赏支持

- 导航最后一组的「赞赏支持」页内置微信赞赏码与支付宝收款码，图片随扩展打包在本地，点击图片可放大查看。
- 页面同时提供「底价接活开发」的服务说明（可承接范围、合作流程与报价方式）；价格按需求评估，不承诺固定金额。
- 联系方式：邮箱 `1399838678@qq.com`、QQ `1399838678`，页面内可一键复制，也提供 `mailto:` 发邮件入口；搜索「QQ」「邮箱」「联系方式」也能直接找到本页。
- 每天首次打开工具箱时弹出一次提示，点击关闭或「今天不再提示」后当天不再出现；右键菜单等任务触发时会自动跳过，避免打断操作。
- 提示状态按本地日期写入 `localStorage`（`ctool.sponsorNoticeShown` / `ctool.sponsorNoticeDismissed`），完整工具箱与小窗共用，不会上传。
- 页面上的「预览提示弹窗」按钮可随时查看效果，且不影响当天的提示状态。

### 网页资源下载

- 一个页面自动扫描出 **IMG 图片 / DOC 文档 / MED 媒体 / TBL 表格** 四类资源，按类型分组显示，每组都可一键全选。
- **IMG 图片**：提取 `<img>`、`srcset` 当前图、CSS 背景图、视频海报、懒加载图片、`og:image` / `twitter:image` 分享图和 Canvas 画布。
- **DOC 文档**：提取 PDF、Word、Excel、PowerPoint、电子书、压缩包、安装包等直链；识别 `download` 属性、嵌入文件、`data-*` 下载地址、JSON-LD 文档地址、网络请求中的文档资源，以及链接文字/路径中含“文库、文档、附件、下载、PDF”等关键词的链接；百度文库等常见文档站点至少会把当前文档页加入列表。
- **TBL 表格**：识别 HTML 表格（自动处理 `rowspan` / `colspan`），并把页面的 `<ul>` / `<ol>` / `<dl>` 及 `role="list"` 列表转换为表格；列表项若包含统一分隔符（`|`、`-`、`：` 等）会自动拆分成多列，可预览并导出带 UTF-8 BOM 的 CSV（Excel 可直接打开）。
- **MED 媒体**：提取 `<video>`、`<audio>`、`<source>`、懒加载 `data-src`、字幕轨和媒体文件直链；m3u8 / mpd 会标注为流媒体清单。
- 支持选择目标标签页、自动扫描、按类型或单条勾选，下载选中项、复制链接，或把所有勾选项打包成 `ctool-downloads.zip`。
- 下载文件统一保存到浏览器下载目录下的 `CTool/下载` 文件夹，重名文件自动加序号；ZIP 内的重名成员也会自动加序号。

## 安装

### Chrome / Edge（桌面版）

1. 解压发布包，或直接使用 `ctool` 目录。
2. 打开扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的 `ctool` 目录。
5. 将 **CTool 万能工具箱** 固定到工具栏，点击图标即可使用。

要求 Chrome / Edge 111 或更高版本（界面使用了 `color-mix()`）。

## 使用

- **打开工具箱**：点击工具栏图标，或按 `Ctrl+Shift+Y`。
- **网页悬浮小窗**：
  1. 在任意普通网页右下角找到 CTool 悬浮图标；
  2. 点击图标，页面内会打开小窗；
  3. 在小窗左侧工具栏选择 35 个工具中的任意一个，直接使用；
  4. 点击小窗右上角的展开按钮可转到完整工具箱，点击关闭按钮或按 `Esc` 收起小窗。
- **切换语言**：点击左下角的语言下拉框选择“简体中文”或“English”，刷新或重开页面后仍然生效。
- **工作台与收藏**：打开左侧“工作台”，选择职业查看推荐工具；点击任意工具右侧的星标即可收藏，收藏会出现在左侧“我的收藏”分组。
- **AI 问答**：打开“AI 助手 → AI 问答”，填写接口地址（如 `https://api.openai.com/v1`）和模型；云端服务填写 API Key，本地服务（如 Ollama）可留空；保存后即可提问，支持流式输出。
- **右键处理选中文本**：
  1. 在任意网页选中文字；
  2. 右键 → **用 CTool 处理**；
  3. 选择 Base64 / URL / HTML 实体 / Unicode 的编码与解码、JSON 格式化或压缩、XML / SQL 格式化、文本统计、计算哈希、解析或验证 JWT、生成二维码、解析 URL、Markdown 预览等；
  4. 当前网页内的小窗会自动打开、载入文本并执行对应操作；
  5. 可以继续修改输入或切换工具，点击右上角的展开按钮可转到完整工具箱。
- **搜索工具**：按 `/`，输入名称或关键词，按 `Enter` 打开第一个结果，按 `Esc` 清空。
- **切换主题**：点击右上角的太阳 / 月亮按钮。
- **下载网页资源**：
  1. 在要处理的网页上点击工具栏图标（或从该网页右键打开 CTool），工具箱会记住来源标签页；
  2. 打开 **网页下载**，工具会自动扫描当前页面并按 IMG / DOC / MED / TBL 分组；
  3. 在“目标网页”下拉框中确认页面，必要时点击“扫描页面”重新扫描；
  4. 通过顶部类型标签筛选，或直接勾选类型组、单条资源；点击“下载选中”批量下载，点击“打包下载 ZIP”合并导出；
  5. 表格和列表支持预览，勾选后可连同其他资源一起下载或打包。

> 首次安装或更新后，如果出现“读取和更改所有网站数据”的权限提示，请允许，否则无法扫描网页内容。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存主题、上次使用的工具、右键菜单待处理文本与来源标签页 |
| `contextMenus` | 提供“用 CTool 处理”的右键菜单 |
| `tabs` | 查找并复用工具箱标签页，列出可扫描的网页标签页 |
| `clipboardWrite` | 复制转换结果、资源链接或 CSV 到剪贴板 |
| `scripting` | 在用户选择的网页中读取图片、链接、表格和媒体信息，并在扩展更新后注入悬浮入口 |
| `downloads` | 批量下载网页资源并保存到分类文件夹 |
| `<all_urls>` | 允许在普通网页中显示悬浮图标、打开小窗，以及扫描用户选择的网页；不会在后台自动读取页面 |

- 扩展不包含任何远程脚本、统计代码或后台网络请求；二维码生成与识别、ZIP 打包所用的第三方库与赞赏码图片都随扩展打包在本地。
- 赞赏提示的显示与关闭状态只写入本机 `localStorage`，不上传到任何服务。
- 二维码识别在本机 canvas 上读取像素完成（jsQR 1.4.0，Apache-2.0，许可证见 `js/vendor-jsqr-LICENSE.txt`），图片不会上传。
- 扫描网页时，提取到的资源列表只在工具箱页面内存中处理，不会上传到服务器。
- 右键菜单带入的文本只在页面内通过 `postMessage` 交给当前标签页的小窗；回退到独立小窗时才通过 `chrome.storage.local` 短暂传递，读取后立即删除。
- 悬浮图标只负责打开小窗，不会主动读取页面内容；只有在小窗中选择网页下载工具并点击扫描时，才会读取当前页面的资源信息。
- 下载由浏览器下载管理器完成；扩展本身不会把文件内容发送到第三方。
- 生成的密码使用 `crypto.getRandomValues()`，不会上传或保存。
- `chrome://`、`edge://`、扩展商店等受保护页面不会显示悬浮图标，也无法扫描；右键菜单在这些页面会退回独立小窗。`file://` 页面需要在扩展详情中手动开启“允许访问文件网址”。

## 开发与打包

项目没有构建步骤，修改源码后在扩展管理页点击“重新加载”即可。

打包为 ZIP 时，让 `manifest.json` 位于压缩包根目录：

```powershell
Compress-Archive -Path F:\ctf\ctool\* -DestinationPath F:\ctf\ctool.zip -Force
```

## 说明

- 本扩展面向桌面版 Chrome / Edge；移动端浏览器不支持扩展。
- 所有转换均在本地完成，但请仍然避免在不可信设备上处理敏感凭据。
- 下载工具只能获取浏览器页面中可见或可访问的资源：受 DRM 保护的视频、需要登录鉴权的临时地址、未渲染的虚拟滚动列表、图片中的文字表格、`chrome://` 页面以及部分防盗链资源可能无法直接下载。
- m3u8 / mpd 下载的是流媒体清单文件本身，不是合并后的视频；如需完整视频，请使用专门的流媒体下载工具。
- 扫描结果是页面当前状态的快照，页面动态加载更多内容后请点击“扫描页面”重新获取。
