## 油猴单文件版（同日追加）
- 用户问「上传的脚本只支持 .js 怎么办」，确认场景后选择产出 UserScript。新增 `build-userscript.js`（可重复运行）与生成物 `ctool.user.js`（约 1.27 MB）。
- 构建思路：按 toolbox.html 的 16 个 `<script src>` 顺序拼接全部 JS，CSS 内联进 `<style>`，两张赞赏码按文件魔数转 Data URL；整份 HTML 作为外层模板字符串在运行时写入 `iframe.srcdoc`，样式/脚本与宿主页面隔离，`document` 语义与原工程一致，因此无需改动任何工具源码。
- 内联转义关键点：JS 中的 `</script` → `<\/script`、`<!--` → `<\!--`，否则会提前闭合或改变 script 解析状态；外层模板字符串需转义 `\`、反引号、`${`，求值后必须能还原原始源码（已验证 96 处模板插值完好）。
- 非扩展环境适配：iframe 引导脚本覆盖 localStorage（同步内存 + postMessage 回传父页面，由 GM_getValue / GM_setValue 跨站保存）、包装 history.replaceState（about:srcdoc 下可能抛错）、提供最小 chrome 垫片（仅 runtime.getManifest/getURL/sendMessage 与 storage 空实现，故意不提供 tabs/scripting/downloads）；覆盖 `CTool.renderers.download` 为不可用说明卡片。
- 宿主侧交互：右下角悬浮 C 按钮、GM_registerMenuCommand、Alt+Shift+C 开关；若站点 CSP 禁止内联脚本则显示提示并提供「在新标签页打开」（GM_openInTab + blob URL）。
- 顺手修正：`assets/sponsor-alipay.png` 实际内容是 JPEG，正名为 `assets/sponsor-alipay.jpg` 并同步 `js/tools-sponsor.js` 与 README；构建器改为按魔数判定 MIME，避免扩展名与内容不符。
- README 新增「油猴单文件版」小节（构建命令、能力差异表、CSP 限制）与目录结构两项。
- 校验：20 个 JS 语法通过；35 定义 ↔ 35 renderer；用模拟 DOM 执行生成物 15/15 通过（iframe srcdoc 1219 KB、零外部引用、3 段内联脚本语法、35 renderer、图片 Data URL、localStorage 桥、chrome 垫片、history 降级、下载工具降级、GM 持久化与关闭消息）。
- 未做浏览器运行时实测；严格 CSP 站点需走新标签回退或改用完整扩展；AI 问答受目标接口 CORS 限制；`@match *://*/*` 不覆盖 file:// 页面。
