## AI 问答改为 OpenCode Zen 零配置（16:00 后）

- 需求：AI 问答内置 opencode-zen，默认无需配置即可问答。
- 实测（2026-11-09）：`https://opencode.ai/zen/v1/chat/completions` 匿名免费层在当前网络对所有组合（空 Bearer / `Bearer public` / 完整 OpenCode 2.2.5 头 / stream+tools）一律返回 429 `FreeUsageLimitError`；`/zen/v1/models` 可匿名访问（CORS `*`）。上游按客户端指纹与 TLS ClientHello 校验，浏览器无法伪造，因此纯 Zen 直连不可靠。
- 方案：默认 Zen + 免费模型队列（内置 7 个 `-free`，可刷新 `/models`）→ 429/5xx 自动换模型 → 仍失败自动回退到 `https://text.pollinations.ai/openai`（model `openai`，实测 200、CORS `*`），开关在高级设置，默认开启，UI/文档明确披露第三方。
- 请求通道：扩展页面 fetch（可流式）+ `ctool-ai-fetch` service worker 兜底；油猴 iframe 用 `CT.aiFetch` → 宿主 `GM_xmlhttpRequest` 桥（新增 `@grant GM_xmlhttpRequest`、`@connect *`），桥环境强制非流式。Zen 匿名请求不发 Authorization，`x-session-id` / `x-opencode-session` 由后台或宿主桥补齐。
- 交互：provider 切换（Zen / 自定义接口）、高级设置折叠、设置自动保存（去掉保存按钮）、模型下拉刷新、右键「💬 问 AI（免配置）」自动载入并提问；旧 `aiConfig`（非 Zen 地址）自动迁移为 custom。
- 改动：`js/tools-extra.js`（AI 模块重写 + `T.aiZen` 导出）、`background.js`、`build-userscript.js`、`css/style.css`、`js/i18n.js`、`js/app.js`、`toolbox.html`、`manifest.json`、中英 README；重新生成 `ctool.user.js`（1418 KB / 17 个内联脚本）。
- 验证：自写测试桩 90/90 通过（全量语法、36 renderer 内联、零外部引用、纯函数、模拟 DOM 零配置问答 / 自动回退 / 关闭回退 / 右键自动提问 / i18n 词条）。仍未做真实浏览器运行时实测。
